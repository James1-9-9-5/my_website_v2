# 08 - Content Inventory

## Publication permissions (read first)
- Get written permission before publishing any client or community project.
- For work with First Nations communities, follow the community's data-governance requirements (for example OCAP principles: ownership, control, access, possession).
- Use generalised locations, sample data, or sensitive-layer-free screenshots where needed.
- Check employer policy (Tapestry Research Group) on publishing project details.
- The Clearance column uses the doc 02 values: `cleared`, `redacted`, `pending`. A `pending` project cannot be published.
