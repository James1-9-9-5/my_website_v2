# 06 - Creative Features

Ideas that make the site memorable. Rank by impact and effort, then pick 1-2 for v1.

| Idea | Impact | Effort | Version |
|------|--------|--------|---------|
| Interactive map on home showing project regions (generalised) | High | Medium | v2 |
| Embedded web map inside a case study | High | Medium | v1/v2 |
| Short intro video on home | Medium | Low | v1 |
| Filter/tags on Work and Lab | Medium | Low | v2 |
| Before/after map slider | Medium | Medium | v2 |
| Dark mode | Low | Low | v2 |

## Rules
- Features must not hurt performance or accessibility.
- Every interactive element needs a non-interactive fallback (image + text).
