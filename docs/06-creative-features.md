# 06 - Creative Features

Ideas that make the site memorable, ranked by impact and effort. With a 2026-11-30 launch, v1 ships the core site only (decision D9); the short intro video is the one optional extra if time allows.

| Idea | Impact | Effort | Version |
|------|--------|--------|---------|
| Short intro video on home | Medium | Low | v1 (optional) |
| Embedded web map inside a case study | High | Medium | v2 |
| Interactive map on home showing project regions (generalised) | High | Medium | v2 |
| Filter/tags on Projects | Medium | Low | v2 |
| Before/after map slider | Medium | Medium | v2 |
| Dark mode | Low | Low | v2 (D3) |

## Rules
- Features must not hurt performance or accessibility.
- Every interactive element needs a non-interactive fallback (image + text).
