# Setup

1. Create a new GitHub repo (e.g. `my-site`) and clone it.
2. Copy everything in this folder into the repo root (`docs/`, `media-source/`, `AGENTS.md`, `CLAUDE.md`).
3. Open the repo in VS Code. Work through docs 00 to 02 first, filling every [bracket].
4. Decide the framework in doc 03 / 11, then start milestone M1 in doc 09.
5. Delete this file when done.
